# 🕊️ Pakhi Chat

**Pakhi** is a modern messaging app designed to help people connect and communicate with each other easily.

* 💬 Chat with friends and family

* 🌐 Modern messaging experience

* Kotlin / Android
* Firebase

## 🚀 Getting Started

### Prerequisites

* Android Studio
* JDK
* Firebase project configuration

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/sazzadSVR/pakhi-chat.git
   ```

2. Open the project in Android Studio.

3. Configure Firebase for your project.

4. Sync Gradle and build the project.

5. Run the app on your Android device or emulator.
